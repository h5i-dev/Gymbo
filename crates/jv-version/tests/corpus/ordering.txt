# Version ordering / equality corpus for the Rust port of Maven version comparison.
#
# Purpose: a machine-readable transcription of the ordering and equality assertions
# made by the upstream Java unit tests, so the Rust implementation can be checked
# against exactly the same expectations.
#
# Transcribed by hand from Apache License 2.0 licensed test sources of the
# Apache Maven Resolver and Apache Maven (maven-artifact) projects:
#   maven-resolver/maven-resolver-util/src/test/java/org/eclipse/aether/util/version/GenericVersionTest.java
#   maven/compat/maven-artifact/src/test/java/org/apache/maven/artifact/versioning/ComparableVersionTest.java
# (helpers: maven-resolver/.../org/eclipse/aether/util/version/AbstractVersionTest.java)
#
# Directive syntax (one per line, blank lines and '#' comments allowed):
#   order  A < B < C        strictly ascending chain: for every i<j, item_i < item_j
#   eq     A == B == C      all listed versions compare equal to each other
#   lt     <A>|<B>          single strict pair, pipe separated (for strings with spaces)
#   eqp    <A>|<B>          single equal pair, pipe separated (for strings with spaces)
#
# The GenericVersionTest section reflects maven-resolver's GenericVersion.
# The ComparableVersionTest section at the end reflects maven-artifact's legacy
# ComparableVersion; the two implementations do NOT agree everywhere. Lines whose
# expectations are believed to conflict with GenericVersion are preceded by a
# '# DISAGREEMENT?:' comment.
