# Corpus: version-CONSTRAINT specifications.
#
# Purpose: machine-readable transcription of every constraint-semantics assertion found
# in the Java test suites, for use by a Rust port. A constraint spec is what
# VersionScheme#parseVersionConstraint accepts: a plain version ("1.0"), a single range
# ("[1.0,2.0)"), or a comma-joined union of ranges ("[1.0,2.0),[3.0,4.0)").
#
# Transcribed from Apache-2.0 licensed test sources of maven-resolver / maven-artifact:
#   maven-resolver/maven-resolver-util/src/test/java/org/eclipse/aether/util/version/GenericVersionSchemeTest.java
#   maven-resolver/maven-resolver-util/src/test/java/org/eclipse/aether/util/version/UnionVersionRangeTest.java
#   maven/compat/maven-artifact/src/test/java/org/apache/maven/artifact/versioning/VersionRangeTest.java
# Implementation reference (semantics of the API being described):
#   maven-resolver/maven-resolver-util/src/main/java/org/eclipse/aether/util/version/VersionSchemeSupport.java
#   maven-resolver/maven-resolver-util/src/main/java/org/eclipse/aether/util/version/UnionVersionRange.java
#   maven-resolver/maven-resolver-util/src/main/java/org/eclipse/aether/util/version/GenericVersionConstraint.java
#
# Grammar (one directive per line; '#' starts a comment line; blank lines ignored):
#   contains  <constraint-spec>  <version>
#   excludes  <constraint-spec>  <version>
#   invalid   <constraint-spec>
#   kind      <constraint-spec>  version        (getVersion() != null, getRange() == null)
#   kind      <constraint-spec>  range          (getRange()  != null, getVersion() == null)
# plus, in the marked union-bound section only:
#   lower     <constraint-spec>  <version> inclusive|exclusive
#   lower     <constraint-spec>  none
#   upper     <constraint-spec>  <version> inclusive|exclusive
#   upper     <constraint-spec>  none
# Fields are whitespace-separated, EXCEPT on lines that contain a TAB: if a line
# contains at least one TAB character, TAB is the field separator for that line
# (used where a verbatim spec copied from Java contains a space).

# === maven-artifact-only: assertions that CONTRADICT maven-resolver semantics ===
# Do NOT feed these to a maven-resolver-semantics implementation.

# source: VersionRangeTest#testContains
# In maven-artifact a plain ("soft") version spec is only a recommendation and its
# restriction is unbounded, so ANY version satisfies it. maven-resolver models a plain
# version constraint as exact equality, where "2.0.4" does not contain 2.0.5.
contains   2.0.4   2.0.5

# source: VersionRangeTest#testInvalidRanges
# maven-artifact rejects overlapping and mis-ordered range unions; maven-resolver's
# UnionVersionRange accepts any set of ranges.
invalid   [1.0,1.2),(1.1,1.3]
invalid   [1.1,1.3),(1.0,1.2]
invalid   (1.1,1.2],[1.0,1.1)
